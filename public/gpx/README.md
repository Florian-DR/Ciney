# Traces GPX de la page Activités

Déposer les fichiers dans ce dossier avec les noms suivants :

- `velo-1.gpx`
- `velo-2.gpx`
- `velo-3.gpx`
- `course-1.gpx`
- `course-2.gpx`
- `course-3.gpx`

La page rend automatiquement le bouton de téléchargement actif dès qu'un
fichier est présent. Les titres, distances et dénivelés affichés sont à
modifier dans `app/views/pages/activities.html.erb`.
